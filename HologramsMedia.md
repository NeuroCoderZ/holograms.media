# Манифест Проекта "Holographic Media"

**Версия:** 3.0
**Дата:** 22 февраля 2026 г.
**Статус:** Действующая спецификация
**Архитектор:** **NeuroCoder**

---

## 1. Концепция: Выход в Многомерность

Мы создаем новый, многомерный язык для взаимодействия человека с информацией и искусственным интеллектом (Триа). Современные интерфейсы ограничены плоскостью; наш проект превращает поток данных в осязаемую цифровую "глину".

## 2. Фундаментальная единица: "Чанк Взаимодействия"

Медиа в нашей системе — это не статический файл, а непрерывный мультимодальный поток:
*   **Звук:** Полный спектр, извлекаемый в реальном времени через CWT-анализ.
*   **Жесты:** Семантические траектории рук, захваченные MediaPipe.
*   **Контекст:** Метаданные среды и состояния системы.

## 3. Архитектура Ядра (Техническая Истина)

### 3.1. Audio Engine (Digital Cochlea)
Центральным узлом управления аудио является **`AudioService.js`**. 
*   **WASM Анализатор:** Используется высокооптимизированный модуль `cwt_analyzer.wasm` на языке Rust. Он выполняет непрерывное вейвлет-преобразование (CWT) для извлечения спектральных характеристик и стерео-панорамы (`panAngles`).
*   **Pipeline:** `MicrophoneManager` / `AudioFilePlayer` → `AudioWorklet` (CwtProcessor) → `EventBus` (`audio:spectralData`).
*   **Adaptive Sync:** Система автоматически подстраивает частоту анализа под частоту обновления дисплея (FPS) для идеальной плавности визуализации.

### 3.2. Визуализация (Hologram Renderer)
За осязаемость данных отвечает `hologramRenderer.js`, использующий **Three.js**.
*   **Local Space Z Shaders:** Шейдеры используют локальные координаты геометрии (`vLocalZ`), что гарантирует стабильность градиента затемнения при любом вращении 3D-сцены.
*   **Grid Physics:** Сетка строго откалибрована на 128 сектонов по оси Y (частота) и динамически реагирует на уровни громкости по оси Z (глубина).

## 4. Триа: Коллективный Разум

Триа — это AI-ассистент, спроектированный для мышления векторами взаимодействия.
*   **Память:** Использование **DataStax AstraDB** для хранения векторных эмбеддингов жестов и звуковых паттернов (Vector Search).
*   **Хранилище:** **Backblaze B2** для долгосрочного хранения медиа-чанков.
*   **Эволюция:** Триа обучается на корреляциях между действиями пользователя и изменениями в структуре голограммы.

## 5. Текущее состояние (Phase 21: NetHoloGlyph)

На февраль 2026 года проект перешел к реализации **NetHoloGlyph**:
*   P2P синхронизация голограмм через WebRTC.
*   Глобальный коллективный сервис Триа.
*   Стабилизация мультиплатформенного UX (Desktop / Mobile / XR).
