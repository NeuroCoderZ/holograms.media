## О проекте

Данный субпроект содержит ядро технологии трехмерной аудиовизуализации для проекта Holograms.Media. Технология включает инновационные алгоритмы обработки аудио и создания интерактивных визуализаций в реальном времени.

## Основные компоненты

### 🔊 Аудио обработка
- **CWT-анализ**: Непрерывное вейвлет-преобразование для анализа частотного спектра
- **WebAssembly модули**: Высокопроизводительная обработка аудио в браузере
- **AudioWorklet**: Асинхронная обработка аудио-потока

### 🎯 Распознавание жестов
- **MediaPipe интеграция**: Отслеживание ключевых точек рук
- **Классификация намерений**: Интеллектуальный анализ жестов
- **Мультимодальный ввод**: Комбинирование аудио и жестового управления

### 🎨 Визуализация
- **Three.js рендеринг**: 3D-графика в реальном времени
- **WebGL/WebGPU**: Аппаратное ускорение
- **Интерактивные эффекты**: Динамическое реагирование на аудио

## Использование

### Встраивание в проекты

```javascript
import { AudioVisualizer } from './audiovis-tech/core';

// Инициализация
const visualizer = new AudioVisualizer({
  container: document.getElementById('visualizer'),
  audioSource: 'microphone'
});

// Запуск
await visualizer.start();
```
