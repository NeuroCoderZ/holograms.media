## Ключевые характеристики (по первоисточникам)

2026-10-14 02:13 MSK — Имя в API: `gemini-4-argon` (и вариант `gemini-4-argon-cyber-permissive` — для киберзащиты). Окно вывода: до 1 000 000 токенов. Уровни «мышления» (thinking): LOW, MEDIUM (дефолт на gemini-4-argon), HIGH (дефолт на cyber-permissive). Поддержка continuation_token (пагинация длинных ответов). Бенчмарки по посредникам: лидерство в enterprise knowledge work и real-world software engineering (DeepSWE, Vals Index). Цена по посредникам: $2 / $10 (за 1M входных / выходных токенов). Мультимодальность: нативно (текст, код, изображения, аудио, видео — по заявлениям Google; для наших задач важен анализ скриншотов голограммы и дампа кода).

2026-10-14 02:13 MSK — Доступ по состоянию на 14.10.2026: в AI Studio модель доступна при плане Google AI (Ultra/Pro) или per-request с API-ключом — именно это показывало баннерное окно «Upgrade to unlock Gemini 4 Argon» на aistudio.google.com скриншота владельца. ## Как использовать в этом проекте

2026-10-14 02:13 MSK — Рекомендованный сценарий (по решению владельца): консультации по архитектуре и разбор дампа — через интерфейс владельца (aistudio/Antigravity/Gemini-приложение), файлы контекста передаются вручную: `repomix-output.txt` (код+документация релиза), `PROGRESS.md` (журнал решений), `GLOBAL_STATUS.md` (срез состояния и открытые решения). Правила передачи: код и документация — английский, ответы и обсуждение — по-русски (владелец не читает английский). Если владелец одобрит платный API — модель следует добавить строкой в LLM_POOL (AGENTS.md, раздел «LLM POOL») с отметкой платности и гейтом, по образцу запрета Yandex SpeechKit; агентам запуск остаётся под запретом до одобрения.
