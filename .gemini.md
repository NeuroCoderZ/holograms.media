# Контекст Проекта Holograms Media

## Пользователь
- Имя: **NeuroCoder** (или **НейроКодер**)
- Обращаться нейтрально и профессионально.

## Ветки и Деплой
- **master**: Главная ветка (Production). Соответствует `holograms.media` (Frontend) и основному бэкенду на Koyeb.
- **dev**: Ветка разработки (Development). Соответствует `dev.holograms.media` (Frontend) и дев-бэкенду на Koyeb.
- **Важно**: Деплой на Cloudflare осуществляется через GitHub Actions, а не через прямую интеграцию Cloudflare с Git.

## Инженерные стандарты
- Использовать режим "Кондуктор" для фиксации прогресса в `conductor/`.
- Перед правками всегда объяснять причину и суть изменений.
- Соблюдать чистоту корня проекта.
