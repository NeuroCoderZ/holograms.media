## Часть I: ДНК Проекта — Философия и Видение

### 1. Генезис: От Идеи к Нейрокодингу
Проект "Holographic Media" — это результат долгой эволюции. Его идейные корни уходят в **2010 год**. С **февраля 2024 года** проект вступил в фазу активной разработки, используя методологию **Нейрокодинга** — симбиотического партнерства между человеком-визионером и AI-ассистентом.

### 2. Миссия: Восстание против Плоского Мира
Мы создаем новый, интуитивный и многомерный язык для взаимодействия человека с информацией, AI и друг с другом, бросая вызов парадигме плоских, текстово-кликовых интерфейсов.

### 3. Философские Принципы Ядра
*   **Скрытая 3D-Интерактивность:** Голограмма — это не "картинка", а осязаемый 3D-инструмент. Ее "плоскость" в ортографической проекции — лишь один из ракурсов. Настоящее взаимодействие начинается в XR, когда пользователь буквально просовывает руки "внутрь" ее глубины, манипулируя звуком как физическим объектом.
*   **Две Сетки — Закон Архитектуры:** Две независимые сетки (левая и правая) — это не просто "стерео". Это два независимых "холста" для творчества, обеспечивающие фундаментальную гибкость для работы с разными источниками, разными руками и разными данными. Это основа для будущего расширения.
*   **Гибкость > Оптимизация:** На старте проекта мы сознательно выбираем архитектуру, которая может принять любые данные (от разных микрофонов, датчиков, рук), а не ту, которая идеально работает только с одним простым случаем. Мыслим "вширь", создавая платформу, а не "вглубь", создавая узкое решение.

## Часть II: Анатомия Системы — Техническая Архитектура

### 4. Каноническое Ядро: `fastcwt_processor`
После ревизии кода и концепции, мы утверждаем, что **`fastcwt_processor`** является **каноническим аудио-ядром** проекта. Его архитектура, основанная на двух независимых каналах и вычислении **разницы фаз** для определения панорамы, идеально соответствует философии "скрытой 3D-интерактивности" и "двух сеток". Все дальнейшее развитие будет строиться вокруг этого ядра.

### 6. Стек Технологий
*   **Frontend:** Чистый JavaScript (ES6 Modules), **Three.js**, **Vite**.
*   **Backend:** **FastAPI** (Python).
*   **WASM-Ядро:** **Rust** (`fastcwt_processor`).
*   **Базы Данных и RAG:** **Tria API** (на базе Cloudflare, `autorag`).
*   **Аутентификация:** **Firebase Authentication**.

### 7. NetHoloGlyph — Кровеносная Система Коллективного Опыта

**7.1. Философия: От Холста к Скульптуре**

`NetHoloGlyph` — это протокол, который превращает индивидуальный "холст" (`Holographic Media`) в общую "цифровую глину". Он позволяет нескольким НейроКодерам одновременно, в реальном времени, видеть, слышать и **изменять** одну и ту же голограмму.

**7.2. Архитектура: Эволюция от WebSocket к WebRTC**

Для минимизации задержек и создания ощущения "прямого контакта", `NetHoloGlyph` v1.0 будет построен на технологии **WebRTC**.

*   **Сигнальный Сервер ("The Matchmaker"):** Наш существующий **FastAPI Backend** будет выполнять роль сигнального сервера. На нем будет реализован WebSocket-эндпоинт, который будет использоваться **только для "знакомства" клиентов**: обмена метаданными сессии (SDP) и кандидатами ICE.
*   **P2P Соединение и Data Channels:** После "знакомства", весь обмен "Голографическими Квантами" будет происходить напрямую между браузерами пользователей через **WebRTC Data Channels**, обеспечивая минимальную задержку.

**7.3. Структура "ГолоГлифа" (Пакета Данных)**

"ГолоГлиф" — это атомарная единица информации, передаваемая по Data Channel в формате JSON.

```json
{
  "type": "quantum_update",
  "userId": "user_id_of_sender",
  "timestamp": 1678886400000,
  "quantum": {
    "dbLevels": [/* 260 float values */],
    "panAngles": [/* 130 float values */]
  },
  "gesture": null
}
```

### 8. Нейрокодинг: Симбиоз Человека и AI
Этот проект разрабатывается в рамках парадигмы **Нейрокодинга**.
