# Лицензирование проекта Holograms.Media

## Обзор лицензионной структуры

Проект Holograms.Media использует гибридную лицензионную модель для обеспечения баланса между открытым развитием, коммерческим использованием и защитой инновационных технологий.

## Структура лицензий

### 1. Основное приложение (MIT License)
**Файл:** `LICENSE` (корень проекта)

**Что покрывает:**
- Основное веб-приложение Holograms.Media
- Пользовательский интерфейс и взаимодействие
- Базовую инфраструктуру
- Стандартные компоненты

**Условия:**
- Свободное использование, модификация, распространение
- Обязательное указание авторства
- Патентная защита от злоупотреблений

### 2. Технология аудиовизуализации (OAVTL)
**Файл:** `docs/Licenses/OAVTL-LICENSE.md`

**Что покрывает:**
- Алгоритмы CWT-анализа
- WebAssembly модули обработки аудио
- Системы распознавания жестов
- Компоненты Three.js визуализации
- Связанные протоколы и алгоритмы

**Ключевые особенности:**
- ✅ **Коммерческое использование разрешено**
- ✅ **Свободное распространение и модификация**
- ❌ **Строго запрещена монополизация технологии**
- 📝 **Обязательное указание авторства: NeuroCoderZ**
- 🛡️ **Защита от патентных претензий**
- 🔄 **Производные работы должны оставаться открытыми**

## Почему такая структура?

### Цели лицензионной модели:

1. **Открытое развитие** - Технология остается доступной для всех
2. **Коммерческая свобода** - Разрешено зарабатывать на основе технологии
3. **Защита от монополизации** - Никто не может единолично владеть технологией
4. **Авторские права** - Сохранение признания вклада NeuroCoderZ
5. **Инновационная защита** - Предотвращение патентных барьеров

### Преимущества для сообщества:

- **Разработчики** могут свободно использовать технологию в своих проектах
- **Компании** могут создавать коммерческие продукты без лицензионных платежей
- **Исследователи** получают доступ к передовым алгоритмам
- **Сообщество** может совместно развивать технологию

## Практическое применение

### Для разработчиков:
```javascript
// Можно свободно использовать
import { AudioVisualizer } from 'holograms-media/audiovis-tech';

// В коммерческих проектах
const app = new AudioVisualizer();
app.start(); // Без лицензионных ограничений
```

### Для компаний:
- Встраивание технологии в продукты
- Создание SaaS-решений
- Разработка собственных приложений
- Все при условии соблюдения лицензии OAVTL
