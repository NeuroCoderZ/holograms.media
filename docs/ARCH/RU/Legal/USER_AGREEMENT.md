1.1. Проект Holographic Media является экспериментальной, исследовательской платформой с открытым исходным кодом.

## 3. Принцип Распределенной Сети и Вклад Ресурсов

3.1. **Фундаментальный Принцип:** Для обеспечения доступности и децентрализации, Holographic Media функционирует как распределенная (peer-to-peer) сеть, где участники взаимодействуют напрямую друг с другом.
3.2. **Отсутствие Центральных Серверов:** Мы стремимся минимизировать зависимость от централизованных, платных серверов. Это означает, что часть нагрузки по обработке и передаче данных ложится на устройства самих пользователей.
3.3. **Добровольный Вклад Вычислительных Ресурсов ("Аренда Микромощностей"):**
    *   Для поддержки работы сети и выполнения сложных вычислений (например, для работы ИИ "Триа" (v3.1) или поддержки децентрализованной сети HoloGraph), приложение может запрашивать у вас разрешение на использование небольшой части вычислительных ресурсов вашего устройства.
    *   **Наше обязательство:** Мы гарантируем, что используемая мощность **никогда не превысит 1% (одного процента)** от общей доступной мощности вашего центрального (CPU) и графического (GPU) процессоров.
    *   Этот механизм является ключевым для выживания и развития проекта и будет основой для будущей справедливой экономики HoloGraph, где участники смогут получать вознаграждение за свой вклад.
    *   Вы будете иметь возможность контролировать и, по возможности, отключать эту функцию в настройках приложения.

## 4. Конфиденциальность Данных

4.1. Мы ценим вашу конфиденциальность. Поскольку большинство данных передается напрямую между пользователями (P2P), они не хранятся на наших центральных серверах.
4.2. Данные, которые проходят через наши вспомогательные сервисы (например, для сигнализации WebRTC), обрабатываются в соответствии с нашей Политикой Конфиденциальности [ссылка на будущий документ].
