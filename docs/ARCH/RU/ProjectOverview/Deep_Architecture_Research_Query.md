# Исследовательский запрос: Глобальная Ревизия Инфраструктуры (v0.20.246)

**Цель:** Провести глубокий технический аудит целесообразности миграции с текущего гибридного стэка на полностью нативный Cloudflare Stack (D1, Workers, Durable Objects) для проекта `holograms.media`.

---

## 1. Контекст и Проблематика
Проект перерос этап простого MVP. Текущая архитектура использует:
- **Frontend**: Cloudflare Pages.
- **Backend**: FastAPI (Koyeb).
- **Database**: Astra DB (Vector Search, 3072d Gemini Embeddings).
- **Storage**: Используется Cloudflare R2 / Backblaze B2.

**Проблема:** Рассинхрон состояний (state synchronization) в NetHoloGlyph и высокие задержки при мультиплеерном взаимодействии. Существует риск «инфраструктурного паразитизма» на дорогих внешних решениях.

## 2. Ключевые вопросы для исследования
1. **Durable Objects vs FastAPI**: Могут ли Durable Objects полностью обеспечить WebSocket-синхронизацию NetHoloGlyph с меньшим пингом и более простым управлением состоянием (Stateful Edge)?
2. **D1 Database**: Справится ли D1 (SQLite на Edge) с нагрузкой метаданных голограмм и хранением эмбеддингов жестов, учитывая наличие `SQLiteEmbeddingService` во фронтенде?
3. **Безопасность и Суверенитет**: Как изоляция в экосистеме Cloudflare повлияет на отказоустойчивость? Не создаем ли мы новую точку зависимости вместо избавления от старых?
4. **Native Blockchain Integration**: Как интегрировать собственный блокчейн (Native HoloGraph Ledger) в Workers? Возможно ли развертывание легковесных нод чейна прямо на Edge?

## 3. Требования к результату
- Сравнительная таблица (Latency, Cost, Scalability).
- Архитектурная схема «Cloudflare-Native».
- Анализ рисков миграции (Breaking changes).
- План поэтапного перехода без остановки текущего R&D.
