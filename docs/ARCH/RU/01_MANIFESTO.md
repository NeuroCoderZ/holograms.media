# AudioChain: Манифест

> Символьный интернет построен на разделении мысли и действия:
> сначала думаешь, потом печатаешь.
> Жестовый интернет уничтожает этот разрыв:
> жест и есть мысль в действии, нераздельно.
> AudioChain — это первый реестр, где мысль
> имеет измеримую стоимость в момент своего возникновения.

## Голографический Квант (DOV)

**DOV = α · Attention(t) + β · Compute(t) + γ · SemanticNovelty(t)**

- **Attention(t)** — стабильность сигнала присутствия (аудио-биометрика)
- **Compute(t)** — вычислительная стоимость программного события (FLOP)
- **SemanticNovelty(t) = 1 − k/N**
  - k = количество смыслов в базе с cosine similarity > 0.85
  - N = общий размер базы смыслов (`gestures_semantic_3072`)
  - **Измеряется смысл, не форма жеста**

α = 0.35, β = 0.30, γ = 0.35 (дефолт, управляется DAO)

## Первичная игра

Носители жестовых языков (в первую очередь глухие)
описывают символьный интернет жестами.
Каждый описанный символ = новый семантический эмбеддинг в базе.
Накопленная база смыслов = базовая ценность AudioChain.

## Ключевое изменение в формуле

| Было | Стало |
|------|-------|
| Novelty = редкость **траектории жеста** | Novelty = редкость **семантического смысла** |
| Сравнивали векторы движения руки | Сравниваем эмбеддинги текстовых меток (3072D) |
| Два разных жеста = высокая новизна | Два жеста с одной меткой ("запустить голограмму") = новизна ≈ 0 |
| Первый с уникальной формой = ценность | Первый с уникальным **смыслом** ("перемотать время назад") = ценность |

## BasilaQ-256

**2 уха × 128 бинов = 256 колонн тора вокруг пользователя**

Угловой шаг сетки остаётся 1.40625° = 180°/128 (неизменно).

Это не удвоение разрешения сетки. Это:
- Переименование алгоритма под антропометрику (бинауральность + бинокулярность)
- Подготовка архитектуры к дуальной обработке (левое/правое поле)
- Сохранение 1.40625° как базовой единицы визуального программирования

> 🧱 Сетка = «голографические кирпичики»: параллелепипеды, из которых можно собирать программируемые 3D-сущности. Жест → семантика → визуальный код → живая голограмма.
