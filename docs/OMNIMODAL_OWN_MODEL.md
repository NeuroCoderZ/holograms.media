## 1. Проблема: почему существующие семейства моделей не подходят

2026-08-10 13:26 MSK

Текущая постановка: **Tria локальная** и **Tria глобальная** работают на семействах моделей с агентом/харнеss Hermes между ними. Но чтобы получить **настоящий** программно-жестовый мультимодальный интерфейс (вход: жест + голос + текст; выход: голограмма/звук/голос/3D-контент), существующих open-моделей в «жестовом» виде недостаточно:

- Модель должна принимать жéстовые токены как модальность (не только текст/звук/изображение);
- Модель должна поддерживать «программистские жестовые возможности» при работе с мультимодальной системой типа **Qwen3.5-Omni**;
- Никакая готовая модель не даёт этого «из коробки».

2026-08-10 13:26 MSK

**Вывод**: нужна **собственная дообученная модель**, которая в итоге становится полностью своей и дообучается постоянно, в идеале — в реальном времени.

## 2. Архитектура Tria: локальная ↔ глобальная

2026-08-10 13:26 MSK

Двухуровневая схема накопления и переработки знаний, объединённая экономикой токенов проекта:

```
            ┌───────────────────────────────────────────────┐
            │          ГЛОБАЛЬНАЯ TRIA (облако)              │
            │  учится от всех персональных триа, поощряет    │
            │  токенами проекта за вклад данных              │
            └───────┬───────────────────────┬───────────────┘
                    │ выгрузка дообученных   │ награда токенами
                    │ персональных данных    │ (нейроэскроу/tokenomics)
        ┌───────────┴────────────┐        ┌──┴─────────────────┐
        │  ЛОКАЛЬНАЯ TRIA #1     │        │  ЛОКАЛЬНАЯ TRIA #N  │
        │  (пользователь активен)│        │  (другие пользователи)│
        │  накапливает данные    │        │                   │
        │  в реальном времени    │        │                   │
        └───────────────────────┘        └────────────────────┘
```

### 2.1 Локальная Tria — сбор во время активности

2026-08-10 13:26 MSK

- **Пользователь активен** → в это время (online) накапливаются **персональные данные Tria**: жесты, голосовые команды, выборы, исправления, преферencies;
- Дообучение локальной модели на этих данных — **инкрементально**, в реальном времени при простое аппаратуры;
- Инференс исключительно на **NPU (50 TOPS)**, не на CPU+GPU (совокупно 9 TOPS на этом ноуте).

### 2.2 Глобальная Tria — обучение от персональных

2026-08-10 13:26 MSK

- Собирает обезличенные/сквозные признаки от множества персональных Tria;
- **Дообучается** на совокупности персональных триа;
- **Поощряет** пользователей за полезный вклад **токенами проекта** (нейроэскроу / tokenomics);
- Обратно раздаёт улучшенные веса/лоро-адаптеры персональным триам.

## 3. Аппаратный базис (проверено на текущем ноуте)

2026-08-10 13:26 MSK

| Компонент | Значение | Комментарий |
|---|---|---|
| CPU | Ryzen AI 5 340 | базовые вычисления |
| iGPU | Radeon 840M, **VRAM динамическая** | при добавлении планки RAM (32GB) → 50% = **~16GB VRAM** |
| NPU | XDNA/Ryzen AI 50 TOPS | **основной инференс**, не GPU/CPU |
| Итого GPU+CPU | ~9 TOPS | НЕ использовать для прожорливого инференса |

2026-08-10 13:26 MSK

- **ROCm ставится несложно**, но сначала определиться с целью (см. §4).
- **Динамическая VRAM**: увеличив RAM до 16GB (планка), из 32GB можно выделить ~16GB VRAM → хватает на инференс 4B-класса.
- **NPU 50 TOPS** — главный вычислитель для инференса и, по возможности, для части обучения.

## 4. Стратегия обучения: free-tier, несколько проходов, начинать с малого

2026-08-10 13:26 MSK

**Ключевые принципы:**

1. **Не сразу модели на триллионы параметров.** Начинаем с малого (классификатор жестов → головы проекции → дообучение малой LLM).
2. **Обучение не одним проходом, а несколькими** — с дообучением по мере поступления данных.
3. **Free-tier нескольких провайдеров** (Kaggle/Colab/Lightning и др., см. skill `free-gpu-compute`) — **пока нет собственных денег** для оплаты обучения.
4. **Unsloth/ROCm НЕ планируем** для обучения (нет оплачиваемого кластера); для этого подходит проверенный free-tier и дообучение.

2026-08-10 13:26 MSK

| Этап | Объект | Масштаб | Инфра |
|---|---|---|---|
| 0 | Жестовый классификатор (малая сеть) | 0.1–5M пар. | локально CPU/NPU |
| 1 | Проекционный head gesture→symbolic | матрица/head | free-tier |
| 2 | Дообучение малой жéстовой сети на персональных данных | инкрементально | локально, online |
| 3 | Единая дообученная модель на базе open-LLM | 0.5–8B | free-tier, многопроходимо |
| 4 | Полная собственная мультимодальная модель | свой | по мере средств |

## 5. Общий пайплайн «жесты → мысль → контент»

2026-08-10 13:26 MSK

Единый нейросетевой цикл, в который вписываются жесты, звук, голос, 3D-визуализация:

```
ВХОД (модальности):  жест (MediaPipe) + голос (GigaAM ASR) + текст
        │  малые классификаторы (инференс NPU 50 TOPS)
        ▼
   Интент-события (дискретные команды)
        │  LLM (собственная мультимодальная, Qwen3.5-Omni-класс)
        ▼
   План действий + генеративные инструкции (подготовка генеративного кэша)
        │
        ▼
ВЫХОД: голограмма (WebGPU) + синтез голоса (собственная TTS) + 3D-контент + аудио
```

2026-08-10 13:26 MSK

Это **делается нейросетями за десятки минут на проход** — ни в коем случае не трактовать как «недели ручной работы». Миллисекунды-«инференс» для активных циклов, минуты для обучающих проходов, часы-недели лишь для накопления данных и дозревшей полной модели.
