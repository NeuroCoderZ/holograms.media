## 1. Обзор: Коллективный Резонанс
**NetHoloGlyph** — это децентрализованный протокол для обмена интенциями в реальном времени. Он превращает индивидуальные экземпляры Триа в единый Рой (Swarm Intelligence), обеспечивая синхронизацию голограмм без задержек центрального сервера.

## 2. Транспортный слой (WebRTC + Signaling)
*   **Сигналинг:** WebSocket-шлюз `wss://dev.holograms.media/ws/signaling` используется только для первичного рукопожатия (Handshake).
*   **DataChannel:** Весь поток интенций идет через **WebRTC Unreliable DataChannel** для минимизации задержек.
*   **Fallback:** При сбое WebSocket протокол автоматически переходит на Long-polling (интервал 5000мс).

## 3. Математика сжатия: QJL 1-bit Quantization
Для передачи многомерных векторов (3072d) через узкие каналы связи используется **Квантованное преобразование Джонсона-Линденштраусса (QJL)**.

### 3.1. Эхолокация Интенций
Вместо передачи полного эмбеддинга, узел транслирует 1-битную сигнатуру:
$$q = \text{sign}(M \cdot v)$$
где $M$ — случайная разреженная матрица. Это позволяет:
*   Сжать вектор в 16-32 раза.
*   Выполнять поиск похожих интенций в Рою со скоростью до 10^6 сравнений в миллисекунду.
*   **TurboQuant Correction:** Добавление одного бита коррекции для сохранения точности косинусного сходства $>99\%$.
