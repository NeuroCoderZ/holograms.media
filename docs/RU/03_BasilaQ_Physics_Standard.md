# Том 3: Физический стандарт BasilaQ-128
**Версия:** 2.8 (Stabilized Physics)
**Дата:** 29 марта 2026 г.
**Статус:** Каноническая спецификация рендеринга

---

## 1. Концепция: Цифровая Базилярная Мембрана
Стандарт **BasilaQ-128** моделирует работу человеческого уха, превращая аудиосигнал в пространственную скейлограмму (Scalogram). В отличие от линейного FFT, мы используем **CWT (Непрерывное вейвлет-преобразование)** для достижения логарифмической точности.

## 2. Квантование Среды (Grid Physics)
Визуальное пространство разделено на дискретную сетку (Voxel Grid) со следующими параметрами:

### 2.1. Частотная ось (Y) — 128 полутонов
*   Диапазон: от 16.35 Гц (C0) до 25087.71 Гц (G10).
*   Разрешение: 12 полутонов на октаву (Musical Standard).
*   **Изоморфизм:** Каждая частотная полоса соответствует одной строке вокселей.

### 2.2. Амплитудная ось (Z) — 1дБ = 1 ячейка
*   Динамический диапазон: 128 дБ.
*   **Формула высоты:** `Z_scale = 128.0 + current_dB`. 
    *   При 0 дБ столбец имеет высоту 128 ячеек.
    *   При -128 дБ столбец исчезает.
*   **Яркость (Z-Dimming):** Интенсивность свечения прямо пропорциональна высоте: `Intensity = Cells / 128`.

### 2.3. Панорамная ось (X) — Дискретность 1.41°
*   **Реализация (v0.20.256):** `cellsToShift = Math.round(p * 64)` → дискретное смещение.
    Это намеренно: сохраняет «цифровую честность» BasilaQ.
*   **Левая (фиолетовая) сетка:** panAngle ∈ [0°, -180°] (от фронта до позади слева). Левая рука.
*   **Правая (красная) сетка:** panAngle ∈ [0°, +180°] (от фронта до позади справа). Правая рука.
*   **Управление:** левая рука → фиолетовая сетка, правая рука → красная сетка.

## 3. Математическое ядро (CWT Core)
Обработка выполняется в модуле `cwt_analyzer.wasm` (Rust cdylib).

### 3.1. Оптимизация Truncated CWT
Для поддержания 60-120 FPS используется усечение носителя вейвлета:
*   На высоких частотах (Bins 96-127) свертка выполняется по усеченному окну (Truncated Window), что экономит до 70% ресурсов CPU.
*   **Pure WASM:** Обмен данными идет через `SharedArrayBuffer` с нулевым копированием.

### 3.2. Фазовая панорама
Угол панорамы вычисляется через разность фаз вейвлетов левого и правого каналов:
$$\Delta\Phi = \text{atan2}(\text{Im}, \text{Re})_{L} - \text{atan2}(\text{Im}, \text{Re})_{R}$$
Результат мапится в диапазон `[-1, 1]` и квантуется в 128 позиций по оси X.
