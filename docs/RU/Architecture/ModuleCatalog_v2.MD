# Каталог Модулей Frontend (Версия 2.0 - Актуализировано)

Этот документ описывает **реальную** структуру и взаимосвязи ключевых модулей JavaScript во frontend части проекта holograms.media. Он служит достоверным источником информации, синхронизированным с кодовой базой.

---

## `/main.js`
- **Назначение:** Главная точка входа приложения.
- **Логика:**
    1.  Инициализирует `ConsentManager` для получения согласия пользователя.
    2.  Вызывает `initCore()` для базовой настройки 3D-сцены и состояния.
    3.  Вызывает `initializeMainUI()` для кэширования DOM-элементов.
    4.  Вызывает `startFullApplication()`, который определяет платформу (`desktop`, `mobile`, `xr`) и динамически загружает соответствующие модули для управления макетом (`...Layout.js`) и вводом (`...Input.js`).
    5.  Запускает главный цикл анимации.
- **Связи:** `core/init.js`, `ui/uiManager.js`, `core/platformDetector.js`, `3d/rendering.js`, `core/consentManager.js`, динамически импортирует модули из `platforms/*`.

---

## `/core/init.js`
- **Назначение:** Инициализирует ядро приложения. Определяет и экспортирует глобальный объект `state`.
- **Экспорты:** `state`, `initCore`.
- **Логика `initCore()`:**
    1.  Вызывает `initializeScene()` для настройки **WebGL** рендерера и сцены. Обрабатывает ошибки инициализации.
    2.  Создает и сохраняет в `state` экземпляры ключевых менеджеров: `HologramRenderer`, `XRSessionManager`, `MicrophoneManager`, `AudioFilePlayer`.
    3.  **Не создает** устаревший `AudioAnalyzer`.
- **Связи:** `3d/sceneSetup.js`, `audio/microphoneManager.js`, `audio/audioFilePlayer.js`, `3d/hologramRenderer.js`, `xr/webxr_session_manager.js`, `ui/panelManager.js`.

---

## `/3d/sceneSetup.js`
- **Назначение:** Отвечает за инициализацию 3D сцены, камеры и **WebGL** рендерера (не WebGPU).
- **Экспорты:** `initializeScene`.
- **Логика:**
    1.  Создает `THREE.WebGLRenderer`. Настраивает обработчики потери и восстановления WebGL контекста.
    2.  В случае ошибки отображает пользователю модальное окно.
    3.  Настраивает ортографическую камеру, сцену и базовое освещение.
- **Связи:** `three.js`.

---

## `/3d/rendering.js`
- **Назначение:** Управляет циклом рендеринга (анимации).
- **Экспорты:** `startAnimationLoop`.
- **Логика:**
    1.  Запускает цикл анимации через `renderer.setAnimationLoop()`.
    2.  В каждом кадре обновляет TWEEN-анимации и рендерит сцену (`renderer.render()`).
    3.  **ВАЖНО:** Вызов `hologramRenderer.updateVisuals()` в текущей версии **закомментирован**, что является причиной отсутствия визуализации. Для восстановления функциональности эту строку необходимо будет раскомментировать.
- **Связи:** `three.js`, `@tweenjs/tween.js`.
