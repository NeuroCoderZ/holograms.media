# Глоссарий Проекта "Голографические Медиа"

**Обновлено:** 14 февраля 2026 г.

## Основные Концепции Проекта

### **Holographic Media (Голографические Медиа)**
Open-source платформа для мультимодальной коммуникации через 3D-аудиовизуализации (голограммы) и AI "Триа". Цель проекта — создание "Неоленга" и "HoloGraph".

### **Неоленг (Neolang)**
Универсальный мультимодальный язык для взаимодействия с данными и искусственным интеллектом, позволяющий пользователям интуитивно управлять сложными системами.

### **HoloGraph (ХолоГраф)**
Децентрализованная экономическая и инфраструктурная система, интегрированная в платформу, обеспечивающая обмен ценностями и управление данными.

### **AI "Триа"**
Искусственный интеллект, являющийся центральным элементом платформы, обеспечивающий мультимодальное взаимодействие, семантический поиск и автономную обработку данных.

### **Мультимодальная Коммуникация**
Взаимодействие, использующее несколько каналов или модальностей (например, звук, визуализация, жесты) для передачи информации.

### **3D-Аудиовизуализации (Голограммы)**
Трехмерные визуальные представления, генерируемые на основе аудиоданных и других входных сигналов, создающие эффект присутствия.

### **Нейрокодер / NeuroCoderZ**
Авторская методология и философия разработки, созданная Александром (NeuroCoderZ). Нейрокодинг — это практика, в которой AI-агенты являются полноправными соавторами проекта, а не инструментами автодополнения. Нейрокодер формулирует архитектурное мышление, ставит задачи, проверяет логику и принимает ответственность за итоговые решения — в непрерывном тандеме с нейросетями. Проект «Holographic Media» создаётся методом нейрокодинга. Ник «NeuroCoderZ» — персональный идентификатор автора, возникший вынужденно из-за занятости оригинального ника в 2024 году.

## Инфраструктура и Развертывание

### **Cloudflare Pages**
Сервис Cloudflare для хостинга и развертывания статических сайтов и одностраничных приложений (SPA), используемый для фронтенда проекта.

### **Koyeb**
Бессерверная платформа для развертывания приложений, используемая для хостинга бэкенда (вычислительных сервисов).

### **AstraDB (на базе Cassandra)**
Единственная распределенная база данных проекта, используемая для хранения глобальных данных и управления состоянием системы. Обеспечивает высокую доступность и масштабируемость.

## Каноническое Ядро (holocore)

### **holocore**
Центральный элемент аудио-пайплайна проекта, реализованный на Rust и скомпилированный в WebAssembly (WASM). Отвечает за вычисление комплексного вейвлет-преобразования (CWT) и Диафоры для Энгармонона (3D-панорамы звука).

### **Rust**
Язык программирования, используемый для разработки `holocore` благодаря его производительности, безопасности и возможностям работы с низкоуровневыми операциями.

### **WebAssembly (WASM)**
Бинарный формат инструкций, предназначенный для выполнения в веб-браузерах. Позволяет `holocore` работать с производительностью, близкой к нативной, непосредственно во фронтенде.

### **AudioWorklet**
API веб-аудио, позволяющий выполнять JavaScript-код для обработки аудио в отдельном потоке, обеспечивая высокую производительность. В нем загружается и выполняется WASM-модуль `holocore`.

### **CWT (Complex Wavelet Transform)**
Комплексное вейвлет-преобразование, математический метод анализа сигналов, используемый в `holocore` для извлечения частотно-временных характеристик аудио.

### **Morlet Wavelet**
Специфический тип вейвлета, используемый в CWT для анализа аудиосигналов, оптимальный для определения локальных особенностей звука.

### **Diaphora (Диафора)**
Разность фаз между аудиосигналами, поступающими с разных источников или воспринимаемыми с разных пространственных позиций. Ключевой параметр, на основе которого строится Enharmonon — трёхмерная звуковая панорама.

### **Enharmonon (Энгармонон)**
Технология создания пространственного звукового эффекта на основе Diaphora (разности фаз), при которой источники звука воспринимаются как расположенные в трёхмерном пространстве вокруг слушателя. Назван в честь древнегреческого энгармонического лада — тончайшего инструмента пространственного слуха.

## Специализированные Технологии и Физика

### **BasilaQ-128**
Математическая модель визуализации, где 1дБ равен 1 ячейке сетки. Физика Z-scale определяется как `128 + дБ`. Интенсивность свечения (Z-Dimming) всегда пропорциональна длине столбца.

### **Cochlear Cylinder (Кохлеарный Цилиндр)**
3D-визуализация на основе тороидальной геометрии, имитирующая структуру кохлеарного аппарата. Используется как основной XR-fallback для иммерсивного опыта.

### **Q-Factor Dome (Купол Q-фактора)**
Интерактивный элемент звуковой модуляции в XR-режиме. Позволяет изменять добротность (Q-factor) фильтров через pinch-жесты.

### **Bathymetry (Батиметрия)**
Техника визуализации глубины аудиочастот по модели BasilaQ-128, обеспечивающая 128-ступенчатую квантованную яркость. Чем больше амплитуда в ячейке — тем «ближе» и ярче она отображается. По аналогии с батиметрической картой океана, где глубина кодируется градиентом цвета.

### **Hermaion (Гермайон)**
Интеграция протоколов Base/x402 (Coinbase), позволяющая AI-агенту Триа самостоятельно совершать микротранзакции и управлять ресурсами в рамках HoloGraph. Назван в честь «дара Гермеса» — бога-посредника.

### **Palinodes (Палинодия)**
Компонент Триа для восстановления пропущенных фрагментов аудиоспектра в реальном времени с использованием кэшированных DFT-таблиц. Название происходит от греческого «петь заново» — Palínodēs буквально «допевает» спектр там, где данных недостаёт.

### **Мнезис / Пауза Мнезиса**
Мнезис — непрерывный фоновый процесс записи и формирования памяти Триа на основе взаимодействий пользователя. Активен по умолчанию. Пользователь может поставить его на паузу через элемент UI «Пауза Мнезиса» для приватности или экономии ресурсов.

## Tria Cortex: Архитектура Памяти

### **Enkephalon (Энкефалон)**
Нейронное ядро Триа, реализованное на Rust и скомпилированное в WebAssembly. Содержит Hebbian-ассоциативную память: матрицу проекции жестов и матрицу ассоциации с намерениями. Работает на стороне клиента.

### **Lethe (Лета)**
Механизм затухания весов нейронной сети Enkephalon: `W *= (1 − λ)`. Знания, которые не используются, постепенно теряют силу — «тонут в Лете». Цикл запускается раз в 24 часа.

### **Obolos (Обол)**
Единица полезности в системе HoloCoin (Proof-of-Utility). Активный, используемый жест = весомый обол. Заброшенный жест стирается Летой.

### **Soma / Pneuma / Sarx (Сома / Пневма / Саркс)**
Три слоя блока памяти Триа:
- **Soma** (тело) — блок данных целиком, живая структура.
- **Pneuma** (дух) — неизменяемое ядро блока (сырые данные, хэш-связь). То, что «было».
- **Sarx** (плоть) — изменяемая оболочка (интерпретация, полезность). То, что «значит».

### **HoloCoin (ХолоКоин)**
Внутренняя валюта экосистемы, используемая для вознаграждения за "Интеллектуальный Майнинг" на основе Оболов.

### **Phonon (Фонон)**
Базовый визуальный и вычислительный квант голограммы, квант звуковой энергии. Аналог пикселя, из фононов строятся колонки BasilaQ-128.
