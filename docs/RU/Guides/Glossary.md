# Глоссарий Проекта "Голографические Медиа"

## Основные Концепции Проекта

### **Holographic Media (Голографические Медиа)**
Open-source платформа для мультимодальной коммуникации через 3D-аудиовизуализации (голограммы) и AI "Триа". Цель проекта — создание "Неоленга" и "HoloGraph".

### **Неоленг (Neolang)**
Универсальный язык для взаимодействия с данными и искусственным интеллектом, позволяющий пользователям интуитивно управлять сложными системами.

### **HoloGraph (ХолоГраф)**
Децентрализованная экономическая система, интегрированная в платформу, обеспечивающая взаимодействие и обмен ценностями между участниками.

### **AI "Триа"**
Искусственный интеллект, являющийся центральным элементом платформы, обеспечивающий мультимодальное взаимодействие и обработку данных.

### **Мультимодальная Коммуникация**
Взаимодействие, использующее несколько каналов или модальностей (например, звук, визуализация, жесты) для передачи информации.

### **3D-Аудиовизуализации (Голограммы)**
Трехмерные визуальные представления, генерируемые на основе аудиоданных и других входных сигналов, создающие эффект присутствия.

### **Нейрокодинг**
Методология разработки, сочетающая человеческий интеллект и возможности искусственного интеллекта для создания программного обеспечения.

## Каноническое Ядро (holocore)

### **holocore**
Центральный элемент аудио-пайплайна проекта, реализованный на Rust и скомпилированный в WebAssembly (WASM). Отвечает за вычисление комплексного вейвлет-преобразования (CWT) и фазовой разницы для 3D-панорамы звука.

### **Rust**
Язык программирования, используемый для разработки `holocore` благодаря его производительности, безопасности и возможностям работы с низкоуровневыми операциями.

### **WebAssembly (WASM)**
Бинарный формат инструкций, предназначенный для выполнения в веб-браузерах. Позволяет `holocore` работать с производительностью, близкой к нативной, непосредственно во фронтенде.

### **AudioWorklet**
API веб-аудио, позволяющий выполнять JavaScript-код для обработки аудио в отдельном потоке, обеспечивая высокую производительность и точность. В нем загружается и выполняется WASM-модуль `holocore`.

### **CWT (Complex Wavelet Transform)**
Комплексное вейвлет-преобразование, математический метод анализа сигналов, используемый в `holocore` для извлечения частотно-временных характеристик аудио.

### **Morlet Wavelet**
Специфический тип вейвлета, используемый в CWT для анализа аудиосигналов, оптимальный для определения локальных особенностей звука.

### **Фазовая Разница**
Разница в фазе между аудиосигналами, поступающими с разных источников или воспринимаемыми разными "ушами", используемая для создания эффекта 3D-панорамы звука.

### **3D-Панорама Звука**
Технология создания пространственного звукового эффекта, при котором источники звука воспринимаются как расположенные в трехмерном пространстве вокруг слушателя.

## Фронтенд (JS/Three.js/Vite)

### **JavaScript (JS)**
Основной язык программирования для разработки пользовательского интерфейса и логики фронтенда.

### **Three.js**
JavaScript-библиотека для создания и отображения интерактивной 3D-графики в веб-браузере, используемая для рендеринга голограмм.

### **Vite**
Быстрый инструмент для сборки фронтенд-проектов, используемый для разработки и оптимизации фронтенда "Holographic Media".

### **`main.js`**
Основной файл фронтенда, который инициализирует приложение и загружает другие модули, включая `init.js`.

### **`init.js`**
Модуль инициализации, отвечающий за запуск ядра `holocore`, пользовательского интерфейса и различных менеджеров.

### **`waveletAnalyzer.js`**
Модуль, содержащий реализацию `AudioWorkletProcessor` ('cwt-processor'), который загружает и управляет WASM-модулем `holocore` для обработки аудио.

### **`AudioWorkletProcessor` ('cwt-processor')**
Специализированный объект в `AudioWorklet`, который выполняет фактическую обработку аудиоданных, используя `holocore` WASM-модуль.

### **`microphoneManager.js`**
Модуль, управляющий доступом к микрофону пользователя и передачей аудиопотока для обработки в `waveletAnalyzer`.

### **`audioFilePlayer.js`**
Модуль, отвечающий за воспроизведение аудиофайлов и передачу их потока в `waveletAnalyzer` для анализа.

### **`hologramRenderer.js`**
Ядро визуализации фронтенда. Получает обработанные аудиоданные (уровни громкости, панорама) от `AudioWorklet` и обновляет 3D-сцену, отображая голограммы.

## Бэкенд (FastAPI/Python на Koyeb)

### **FastAPI**
Современный, быстрый (высокопроизводительный) веб-фреймворк для создания API на Python, используемый для бэкенда проекта.

### **Python**
Основной язык программирования для разработки логики бэкенда, обработки данных и взаимодействия с базами данных и внешними сервисами.

### **`app.py`**
Точка входа бэкенд-приложения, где инициализируется FastAPI и подключаются роутеры API.

### **REST API (`/api/v1/*`)**
Набор эндпоинтов, предоставляющих функциональность для управления голограммами, чатом, командами Триа и другими сервисами через стандартные HTTP-запросы.

### **WebSocket**
Протокол двусторонней связи по одному TCP-соединению, используемый для обмена данными в реальном времени между клиентом и сервером.

### **`/ws/v1/gesture-intent`**
WebSocket-эндпоинт на бэкенде, который принимает намерения, распознанные по жестам пользователя, в реальном времени. Требует аутентификации.

### **`/ws/signaling`**
WebSocket-эндпоинт, используемый для сигнализации WebRTC (NetHoloGlyph), координирующий установление P2P-соединений.

### **JWT (JSON Web Token)**
Стандарт для создания токенов доступа, используемых для безопасной аутентификации и авторизации пользователей в сессии после валидации токена Google.

## Сетевое Взаимодействие (NetHoloGlyph 2.0)

### **NetHoloGlyph 2.0**
Концепция "Цифрового векторного котла" для обмена мультимодальными данными между участниками, использующая WebRTC и WebSocket.

### **WebRTC (Web Real-Time Communication)**
Технология, позволяющая осуществлять P2P-связь (peer-to-peer) в реальном времени непосредственно между браузерами или устройствами, минуя сервер.

### **Data Channels (Каналы Данных WebRTC)**
Функциональность WebRTC, позволяющая передавать произвольные данные (не только аудио/видео) между пирами в реальном времени.

### **P2P-связь (Peer-to-Peer)**
Прямое соединение между двумя устройствами без промежуточного сервера, обеспечивающее низкую задержку и высокую пропускную способность.

### **Fallback на WebSocket**
Механизм, при котором, если прямое P2P-соединение через WebRTC не может быть установлено, связь осуществляется через WebSocket-сервер.

## Аутентификация

### **OAuth 2.0 от Google**
Стандартный протокол авторизации, используемый для аутентификации пользователей через их учетные записи Google.

Процесс проверки подлинности и целостности токена, полученного от Google OAuth 2.0, на стороне бэкенда для подтверждения личности пользователя.
