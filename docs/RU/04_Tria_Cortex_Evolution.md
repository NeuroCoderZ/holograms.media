## 1. Архитектура Памяти: Soma и Hippocampus
Память Трии строится по принципу биологического резонанса, а не статического хранения логов.

### 1.1. Soma-блок (Квант Опыта)
Единицей памяти является **Soma-блок** (реализовано в `LocalChain.js`). Структура блока:
*   **Pneuma (Дух):** Неизменяемые данные. Хэш предыдущего блока, временная метка, сырые координаты MediaPipe и CWT-вейвлеты.
*   **Sarx (Плоть):** Изменяемые данные. `utility_score` (полезность), `maturity_level` (зрелость от 0 до 100) и `plasticity` (способность к изменению).

### 1.2. Hippocampus (L1/L2 Cache)
*   **L1 (Мгновенная):** Индексированная база данных в **IndexedDB** (`TriaMemory.js`). Хранит последние 500 Soma-блоков для мгновенного резонанса.
*   **L2 (Долговременная):** Синхронизированная коллекция в **AstraDB** (3072d эмбеддинги). Используется для поиска аналогий в глобальном опыте Роя.

## 2. Циклы Сознания: Lethe и Maturity
Триа — это живой процесс, требующий очистки и сна.

### 2.1. Lethe Cycle (Цикл Забвения)
Реализовано в `MaturityDaemon.js`. Каждые 24 часа запускается процесс девальвации:
*   `utility_score *= 0.9` (ослабление нейронных связей).
*   Блоки с `utility_score < 0.01` удаляются, освобождая когнитивное пространство.
*   Это предотвращает "галлюцинации памяти" и перегрузку NPU.

### 2.2. Maturity (Зрелость)
Если жест успешно предсказан (Resonance > 0.85) и подтвержден действием пользователя, его `maturity_level` растет. При достижении уровня 100 блок становится "каноническим навыком".

## 3. Эволюция через данные (Meta-слой)
Триа эволюционирует безопасно — через данные, а не через самомодификацию кода.
*   **MetaInstructionService** (`meta_agent.py`): обновляет системные инструкции как записи AstraDB.
    Глобальная Триа может отправлять персонализированные "прошивки" поведения каждой персональной копии.
*   **Darwin Critic** (`tria_orchestrator.py`): генерирует варианты A/B, SUB_MODEL выбирает лучший.
*   Пользователь может промптингом задавать правила для своей Трии.
*   ⚠️ Прямая самомодификация Python/JS кода — не реализована и не планируется без sandbox.

---

## 4. Метрики качества Триа (внутренние, не ARC-AGI)
1.  **confidence:** ≥ 0.85 для прямого исполнения жеста (`GestureEmbeddingBridge.js`).
2.  **utility_score:** [0.0, 1.0] — ценность Soma-блока, убывает по формуле `U *= 0.9` каждые 24ч.
3.  **maturity_level:** [0, 100] — зрелость навыка. При 100 — канонический навык.
4.  **Early Trigger:** предиктивное исполнение при confidence ≥ 0.85 на 300-500мс жеста.
