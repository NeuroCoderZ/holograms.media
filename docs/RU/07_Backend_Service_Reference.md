## 1. Архитектура сервера (FastAPI)
Бэкенд представляет собой высокопроизводительное асинхронное приложение на **FastAPI 0.135.1**.

### 1.1. Жизненный цикл (Lifespan)
При старте сервера инициализируются:
*   **Astra DB Client:** Подключение к векторному хранилищу.
*   **S3 Client (Boto3):** Связь с Cloudflare R2 / Backblaze B2.
*   **Tria Orchestrator:** Инициализация супервизора моделей.

## 2. API v1: Основные эндпоинты

### 2.1. Интеллект и Чат
*   **`POST /api/v1/tria/prompt`**: Принимает текстовый запрос, возвращает ответ Трии с учетом контекста RAG.
*   **`POST /api/v1/chat/users/me/chat_sessions/direct`**: Потоковая передача ответа (SSE). Поддерживает передачу `thought_blocks` (внутренних рассуждений).
*   **`WS /ws/v1/tria/live`**: Двусторонний стриминг аудио (PCM 16kHz) для Multimodal Live API.

### 2.2. Жесты и Биометрия
*   **`POST /api/v1/gestures`**: Сохранение траекторий MediaPipe в AstraDB.
*   **`GET /api/v1/users/me/gestures`**: Получение списка личных жестов пользователя.
*   **`POST /api/v1/gesture-embedding`**: Генерация вектора (3072d) через Gemini Embedding 2.

### 2.3. Экономика (Wallet)
*   **`POST /api/v1/wallet/obolos/earn`**: Начисление токенов на основе подтвержденных жестов.
*   **`GET /api/v1/wallet/obolos/balance`**: Просмотр текущего баланса Utility Unit.

## 3. База данных: AstraDB (Cassandra)
Используется **Data API v2.2** с поддержкой высокоразмерных векторов.
*   **Размерность:** 3072 (стандарт Gemini 2).
*   **Метрика:** `COSINE` (косинусное сходство).
*   **Оптимизация:** При поиске используется бинарное кодирование `DataAPIVector` для экономии трафика.

## 4. Стордж (R2 / B2)
*   Все медиа-чанки (аудио/видео) сохраняются в S3-совместимое хранилище.
*   Доступ осуществляется через временные **Presigned URLs**.
