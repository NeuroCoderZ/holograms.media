## 1. Облачная архитектура (Cloud Stack)
Проект Holograms Media использует гибридную инфраструктуру для обеспечения максимального edge-резонанса.

### 1.1. Cloudflare Ecosystem
*   **Workers Assets:** Фронтенд и статика развернуты через унифицированный Workers Assets (стандарт 2026).
*   **Dynamic Workers:** Для выполнения сгенерированного Триа кода (GestureToCode) используются изолированные песочницы `env.LOADER.load()`.
*   **D1 Database:** Хранение метаданных сессий и конфигураций пользователей.
*   **Prefix Caching:** Система кэширует системные промпты Трии на узлах Cloudflare для мгновенного инференса.

### 1.2. Backend (Koyeb & Docker)
*   **Среда:** Python 3.11 Slim в Docker-контейнерах.
*   **Оркестрация:** Koyeb управляет автомасштабированием в зависимости от нагрузки на Tria Live API.

## 2. Пайплайн развертывания (CI/CD)
Автоматизация реализована в скрипте `scripts/deploy.js`.

### 2.1. Цикл "Code-to-Knowledge"
Каждый деплой включает:
1.  **Versioning:** Инкремент патч-версии в `package.json` и `index.html`.
2.  **RAG Sync:** Принудительный вызов `python scripts/sync_knowledge_base.py`. Это синхронизирует изменения в `docs/RU` с векторной базой **AstraDB (3072d)**.
3.  **Git Push:** Пуш в ветку `dev` для автоматического билда.
