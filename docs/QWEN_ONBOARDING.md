## 1. Кто мы и что за проект

**holograms.media** — «цифровой тамбур» между плоскими дисплеями и голографической реальностью.
Голограмма выступает GUI с **несимвольным** взаимодействием: жест и голос первичны, а не текст.

Проект входит в семейство NeuroCoderZ (три связанных репозитория):
- **holograms.media** — голографический интерфейс, ветка `dev`, стенд `dev.holograms.media`
- **NeuroEscrow** — финансы/эскроу, ветка `main`
- **CoderzVoice** — голосовой стек, ветка `main`

**Стек:** ванильный JS + WebGPU (собственный движок HoloEngine) + WebXR + WebRTC/WebSocket,
Python-бэкенд (FastAPI) на Koyeb, фронт на Cloudflare Pages.

**Стратегическая линия:** полный отказ от Three.js в пользу нативного WebGPU. Сейчас
осталось 15 файлов с Three.js, миграция на финальной стадии.

**Масштаб:** 424 файла в графе (226 JS + 185 Python), 417 файлов в repomix, ~694 тыс. токенов.

## 2. Зачем ты нужен — прямо и без обиняков

**Экономия денег.** Opus 5 — дорогая модель. Чтение тысяч строк логов из консоли браузера
или 694-тысячетокенного репомикса на Opus 5 — прямое транжирство: сотни центов уходят на
задачи, где не требуется глубокое рассуждение, только внимательный разбор объёма.

Ты — умный, стабильный, с большим бесплатным контекстом и интернетом. Поэтому:

| **Гермес (Opus 5)** | Правки кода, архитектурные решения, отладка, деплой, ревью твоих находок |

## 5. Правила проекта, которые нельзя нарушать

1. **Деплой только `npm run deploy "сообщение"`** — он бампает версию (+0.001). Прямой
   `git push` — нарушение процесса.
2. **Локальных сборок не делать** — только CI.
3. **Repomix только txt** во всех проектах NeuroCoderZ.
4. **Даты в документации:** каждый абзац начинается с `YYYY-MM-DD HH:MM MSK`.
5. **Никаких массовых удалений из БД** — только точечные изменения.
6. **Фактчекинг:** технические утверждения — из официальной документации или из кода,
   не из памяти модели.
7. **Отвечать по-русски.**

## 6. С чего начать — первое задание

Открой `repomix-output.txt` и дай отчёт по трём вопросам:

**A. Мёртвый код.** Модули, которые никто не импортирует и не инстанцирует. Мы уже удалили
так `EarthZero.js`, `CochlearCylinder.js`, `SmartHologram.js` — ищи такие же. Для каждого
кандидата: путь, почему считаешь мёртвым, кто (не) ссылается.

**B. Спека ≠ реализация.** Места, где документация обещает то, чего нет в коде. Известный
пример: `docs/RU/05_NetHoloGlyph_P2P_Protocol.md` описывает QJL-сжатие и постквантовый ML-KEM,
а в коде — обычный `JSON.stringify` по WebRTC, без какого-либо шифрования и сжатия.

**C. Остатки Three.js.** 15 файлов ещё импортируют Three. Составь порядок их отключения
с учётом зависимостей: что можно убрать сразу, что тянет за собой другие модули.

Формат: список находок, каждая — «файл:строка → суть → что предлагаешь».
