## Часть A. Основные Концепции Проекта

### Holographic Media (Голографические Медиа)
Open-source платформа для мультимодальной коммуникации через 3D-аудиовизуализации (голограммы) и AI «Триа». Цель — «Неоленг» и «HoloGraph».

### Неоленг (Neolang)
Универсальный мультимодальный язык взаимодействия с данными и ИИ.

### HoloGraph (ХолоГраф)
Децентрализованная экономическая и инфраструктурная система платформы.

### AI «Триа»
Центральный ИИ: мультимодальное взаимодействие, семантический поиск, автономная обработка данных.

### Мультимодальная Коммуникация
Взаимодействие через несколько каналов (звук, визуализация, жесты).

### 3D-Аудиовизуализации (Голограммы)
3D-представления из аудиоданных и других сигналов, создающие эффект присутствия.

### Нейрокодер / NeuroCoderZ
Методология разработки, где AI-агенты — полноправные соавторы проекта. Автор: Александр (NeuroCoderZ).

## Часть C. Целевой вебстек (WebGPU + WebXR + WebSocket + WebRTC)

### Три раздельные оси (картинка / состояние / устройство)

| Ось | Технология | Что решает | Файлы |
|-----|-----------|-----------|-------|
| **Картинка (локальная)** | WebGPU | рендер голограммы каждому клиенту | `js/engine/*` |
| **Состояние (общая)** | WebRTC + WebSocket | синхронизация поз/жестов/присутствия | `js/services/*` |
| **Устройство (иммерсивность)** | WebXR | VR/AR-сессии, поза гарнитуры | `js/xr/*` |

### Ядро рендера (WebGPU)
- **HoloEngine** — нативный WebGPU-движок, один canvas, шейдеры WGSL, свой рендер-луп.
- **Инстанс-столбцы** — 256 столбцов, 2 draw call, 3-буферный лейаут (10× меньше шины GPU).
- **Каркасная сетка** — подложка-сетка сцены.
- **Камера (единая)** — единый источник позы (eye/target) движения (yaw/pitch/zoom). Два домена проекции:
  - **Ортографическая** — параллелепипедная голограмма на **плоских дисплеях** (единицы голограммы ±150).
  - **Перспективная** — торообразная голограмма в **XR-очках** (FOV 75°, 1 unit = 1 метр).
  - Каждый домен сохраняет свою проекцию; общий — только поза (eye/target). В XR позу задаёт гарнитура.

### Граф сцены
- **Holoworld** — общий мир/сцена примитивов (замена `THREE.Scene`).
- **Пировый мир** — визуализация присутствия других клиентов (замена `EarthZero` / `EarthZero_Layer`).
- **Маркер присутствия** — отметка в общем мире о присутствии/действии другого клиента (замена «эхо» / `addEcho`).
- **Хологлиф** — смысловое имя голокванта со стороны протокола NetHoloGlyph. **Стабилен, не менять.**

### XR (WebXR)
- **Сессия XR** — `navigator.xr.requestSession('immersive-ar'/'immersive-vr')` (замена `renderer.xr`).
- **XRGPUBinding** — связка WebGPU swap-chain с WebXR Layers.
- **Поза гарнитуры** — источник камеры в XR (замена `state.xrCamera`).
- **Ортокамера** — базовая проекция для голограммы (честная калибровка дБ в любом режиме).
- **Обратная (реверсивная) перспектива** — спец-проекция, тестируется для XR-тора: ближнее меньше, «разворот на зрителя» (решение Нейрокодера 10.08). Отдельный эксперимент Шага 6.

### Мультиплеер (WebSocket + WebRTC)
- **Сигналинг** — WebSocket-обмен SDP/ICE для установки соединения.
- **Канал состояния** — WebRTC DataChannel для синхронизации общего состояния.
- **Контракт состояния** — единый объект: поза + маркеры присутствия + жесты.

### Вход & жесты
- **Орбита камеры** — drag/wheel/pinch → `Engine.orbit/setZoom/zoomBy` (замена `OrbitControls`).
- **Нативный пикинг** — луч в ячейку графа по pan/depth из dynamic-буфера (замена `THREE.Raycaster`).

## Часть D. Каноническое Ядро (holocore) — аудио-стек

- **holocore** — ядро аудио-пайплайна на Rust/WebAssembly. CWT + Диафора для Энгармонона.
- **Rust** — язык реализации holocore.
- **WebAssembly (WASM)** — бинарный формат, near-native производительность в браузере.
- **AudioWorklet** — потоковая обработка аудио; в нём исполняется WASM holocore.
- **CWT (Complex Wavelet Transform)** — комплексное вейвлет-преобразование.
- **Morlet Wavelet** — вейвлет для CWT-анализа, оптимум для локальных особенностей звука.
- **Diaphora (Диафора)** — разность фаз между аудиосигналами из разных позиций.
- **Enharmonon (Энгармонон)** — пространственный звук на основе Диафоры (3D-панорама вокруг слушателя).

## Часть E. Специализированные Технологии и Физика

- **BasilaQ-256** — 1 дБ = 1 ячейка сетки; Z-scale = `128 + дБ`; свечение ∝ длина столбца.
- **Cochlear Cylinder (Кохлеарный Цилиндр)** — тороидальная 3D-визуализация кохлеарного аппарата; XR-fallback.
- **Q-Factor Dome (Купол Q-фактора)** — изменение добротности фильтров через pinch в XR.
- **Bathymetry (Батиметрия)** — 128-ступенчатая квантованная яркость (глубина = «ближе/ярче»).
- **Hermaion (Гермайон)** — интеграция Base/x402 (Coinbase) для микротранзакций Триа.
- **Palinodes (Палинодия)** — восстановление пропущенных фрагментов аудиоспектра (кэш DFT).
- **Мнезис / Пауза Мнезиса** — непрерывная запись памяти Триа; пауза через UI.

## Часть F. Tria Cortex: Архитектура Памяти

- **Enkephalon (Энкефалон)** — нейронное ядро Триа (Rust/WASM), Hebbian-память: матрица проекции жестов + матрица намерений. Клиентская сторона.
- **Lethe (Лета)** — затухание весов: `W *= (1 − λ)`, цикл раз в 24 ч.
- **Obolos (Обол)** — единица полезности (Proof-of-Utility). Активный жест = весомый обол.
- **Soma / Pneuma / Sarx** — три слоя блока памяти: тело (данные), дух (неизменяемое ядро), плоть (изменяемая интерпретация).
- **HoloCoin (ХолоКоин)** — внутренняя валюта, вознаграждение за «Интеллектуальный Майнинг».
- **Phonon (Фонон)** — базовый визуальный/вычислительный квант голограммы; из фононов строятся колонки.

## Часть H. Неологизмы ячеистого канона (2026-08-09)

- **Голобит** — состояние одной ячейки: залита/нет. 1 бит, аналог пикселя шрифта.
- **Голоквант** — минимальная осмысленная единица: колонна (полутон + глубина дБ + пан). 128 голобитов → термокод + пан. Отвечает: что звучит, как громко, откуда.
- **Гологлиф** — голоквант как носитель смысла (сторона протокола NetHoloGlyph). Смысловой аспект голокванта.
- **Голокадр** — вся голограмма в момент времени: 2 сетки × 128 полутонов = 256 голоквантов.
- **Голомация** — последовательность голокадров во времени (голограмма + анимация, 24–240 Гц).

## Часть J. Экономика внимания (2026-09-30)

> Канон: `docs/ATTENTION_ECONOMY.md`. Здесь только слова.

- **Секунда звука (SND)** — **единица кодека.** 1 секунда эволюции голомации = **344 метра** звукового пространства (скорость звука в воздухе). Связывает пространство и время **внутри кодека**. Константа физики, не экономики.
- **AVT (аудиовизуальное время)** — **единица внимания.** Носитель несёт и звук, и картинку, поэтому единица внимания аудиовизуальная, а не «звуковая». Связь: **одна AVT голомации разворачивается на 344 метра звукового пространства.** Физическая связь. Курс «AVT ↔ компенсация вычислений» — **рыночный** и зависит от мощности железа: во второй секунде при большем вычислении умещается работы на минуты и часы.
- **Внимание** — **инпут.** Работа вычислительных мощностей устройства на разворачивание голограммы. Оплачивается **секундами жизни**. **Это активность в сети NetHoloGlyph, а НЕ нахождение на платформе.** Поток: не хранится, не накапливается, не печатается.
- **Черновик** — жесты придумываются и обкалываются со своей Триа, **никому не передаются**. Стоит ноль и **не вредит**: §5 срабатывает только по факту состоявшейся передачи. Обмен знаниями с собственной Триа заработку не мешает.
- **Проба** — отправлено одному. Фидбэк от одного.
- **Распространение** — отправлено одному, тот передал десятку. **В разы выгоднее.**
- **Генерация** — **аутпут.** Контент, созданный жестами и упакованный в голограмму с вложенными метаданными.
- **Токен проекта** — **выход.** Компенсация вычислительных ресурсов. **Эмиссия ровно 1.0**, держит Глобальная Триа. Термин **«секунда звука» в применении к токену ошибочен** — см. AVT.
- **Аудиторная секунда** — секунда, удержанная автором, потому что его работа была **передана и воспринята**.
- **Рефлексивный возврат** — работа, не выполнившая своей функции (не принята и не ушедшая дальше от внимающего к новым внимающим), **возвращает токен отправителю сам.** Возврат не наказывает за неудачу, **а оплачивает маркетинг**: автор за один круг получает фидбэк от десятка и понимает, что делать дальше.
- **Термостат доли Глобальной Триа** — её доля **меняется в обе стороны**: падает при активной сети, растёт при молчащей. Сумма долей всегда 1.0. Следовательно доля есть **индикатор живости сети, работающий без управления.**
- **Система вознаграждает цепляющий контент** — следует из рефлексивного возврата по построению: вознаграждается только то, что распространяется.

## Часть K. Контракты, сеть, подтверждение (2026-09-30)

- **Голоконтракт** — **шестая ступень** лестницы единиц. Передаваемый, исполняемый и принадлежащий объект. Исполняется **непрерывно**: «пока(створка идёт) { звук = f(фаза, скорость) }». Не транзакция, а подписка на поведение. Газ здесь — **звук**. Шесть полей: СУБЪЕКТ, УСЛОВИЕ, ОТОБРАЖЕНИЕ, СРОК, СТОРОНЫ, ЦЕНА. Четыре действия жизненного цикла: **создание, изменение, реализация, прекращение.**
- **Своя атмосфера** — персональный слой поверх Earth_0. Область действия — **только там, где пользователь есть сейчас и где был ранее**: атмосфера есть **след, а не пузырь**. Атмосферы смешиваются и рециркулируют друг в друга через NetHoloGlyph.
- **Цепочка цепочек** — структура, в которой цепочка жестов может содержать **любое количество вложенных цепочек**. Глобальная Триа обучается на таких цепочках.
- **Мотив** — повторяющийся структурный оборот в цепочках, который Глобальная Триа способна опознать. **Смысл жеста при этом остаётся приватным автора**: единого жестового языка нет, каждый наделяет свои жесты своим смыслом. **Триа осведомлена о структуре, но не о значении.**
- **Двойное событие** — два и более участника **синхронно генерируют и тут же внимают**. Неважно, рядом ли они физически или только через интернет. **Деление на производителей и потребителей снимается.**
- **Удостоверение** — подписанный хеш физического факта: идентификатор голоконтракта, координаты куба, временной отрезок, число вызванных секунд, число подтвердивших наблюдателей, подпись устройства-наблюдателя. **Нотариусом служит сама голограмма: доверенная третья сторона не нужна.**
- **Идентификатор голоконтракта** — **единый номер документа для двух платёжных систем одновременно.** Как номер накладной, по которому и банк, и налоговая видят одну сделку.
- **Точка размыкания** — GRAM ↔ цифровой рубль. **Разомкнута по умолчанию.** До появления Платформы коммерческих смарт-контрактов Банка России шов держится на человеке-обменнике. Правильная форма — **не один мост, а много обменников**: удостоверение является их общим интерфейсом, конкуренция встроена.
- **Вампир-эффект** — машины не могут захватить сеть, но **каждое машинное наблюдение выпивает железо и энергию**. Счёт платности машины ведётся в том же потоке, что и доход. Укус — расход, а не захват.
- **Три сорта внимания** — **присутствие** (человек в XR, осознанно, высшая цена), **машинное восприятие** (камера, арендованное железо, средняя), **автономный агент** (машина без человека, низшая). Не даёт вычислительной ферме выкупить всё внимание.
- **Пакман-ограничение** — число машин-наблюдателей ограничено человеческим вниманием **по построению**: `Σ(стоимость машин) ≤ Σ(внимание, произведённое людьми)`. Машины питаются человеческим вниманием, значит не могут превзойти его. Это **закон, а не политика.**
- **Залог вниманием** — отличие маркетплейса NeuroEscrow от Workzilla, FL.ru и Kwork. Те удерживают **деньги** (взаимозаменяемы, выводимы). Залог вниманием требует живого наблюдателя, живого устройства и живых секунд, **поэтому невыводим и неодолжим**: одновременно дефицитен, неподделен и невыводим.
- **NeuroEscrow** — **маркетплейс услуг** по образцу Workzilla / FL.ru / Kwork, реализованный мини-приложениями в Телеграме и MAX. Нейрокодер реализует идею клиента речевым нейрокодингом через CoderzVoice, **без ручного программирования**. Выручка в цифровом рубле и GRAM тратится на оборудование для серверов голографических медиа — **инфраструктура финансируется выручкой от самой себя.**
- **Персональная Триа** — жестово-символьный ИИ, помогающий работать с платформой голографических медиа **и ведущий бухгалтерию пользователя ИИ.** Вторая функция не менее важна. **С OlgaHerz не связана.**
- **OlgaHerz** — **отдельный проект**, персональный ИИ-контур. Архитектурной связи с Персональной Триа нет.
- **Речевое воплощение символьной информации** — **речь есть звуковое воплощение записи, которая может быть и визуально записана; но запись НЕ динамична — динамику создаёт движение глаз слева направо**, величина и рисунок которого зависят от способа записи символов в языке. **Речь возвращает утраченное измерение.**
- **Токен-коннект** — **рынок разрешений, а не рассылка.** Генератор жестами определяет, что видит и слышит сам; если ему нравится, запрашивает разрешение у других, предложив токен-коннект, и транслирует им то, что они будут рады видеть и слышать, **с точки зрения и слышания человека-генератора.** Токен-коннект выполняет четыре роли: инструмент разрешения, носитель передачи, вознаграждение, доказательство согласия. **Передаётся не звук, а отношение генератора к звуку** — получатель получает перерисовку, а не копию. Переносится способ отношения, а не файл.
- **Дубляж как генерация** — **дубляж есть перевод, а перевод есть генерация.** Поэтому тот, кто доносит звук в иной канал, получает за это вознаграждение наравне с автором. Жестовый язык есть уже система синхронного дубляжа: перевод звука в зримую форму в реальном времени без символов. Голограмма продолжает то же для звука.
- **Персональная Триа = АГЕНТ [CURRENT]** — **чистый агент, символьно-жестовая.** Помогает работать с платформой голографических медиа **и ведёт бухгалтерию пользователя ИИ** (вторая функция не менее важна). **С OlgaHerz не связана.**
- **Глобальная Триа = ХАРНЕСС [CURRENT]** — **чистый харнесс (сбруя, вожжи) для агента, чисто жестовая.** Именно поэтому DeepSeek Harness был аналогией, а не кандидатом: бралась его конструкция — связность, всё есть плагин — и писалась своя. Не имеет символьного слоя, поэтому работает на стыке эмбеддингов из символов и из жестов фоновым поиском среднестатистических закономерностей.
- **Жестово-нейроинтерфейсная точка выхода** — возможная следующая стадия эволюции Глобальной Триа: **чтение жестовых областей мозга напрямую, без необходимости исполнять жесты руками.** Обозначено как направление, не как задача.
- **Мини-приложение** — официальное название клиентских приложений внутри MAX (аналог Telegram Mini Apps). Архитектура совпадает: глобальный объект `window.WebApp`, поля `initDataUnsafe.start_param` и `initData`, диплинки вида `max.ru/?startapp=`. Работают **только внутри чат-ботов**, автономно существовать не могут; построены на обычных веб-технологиях HTML/JS/CSS. **Подключение к платформе MAX для партнёров доступно юрлицам, ИП и самозанятым — резидентам РФ.**

## Часть I. Правила переименования (наследие Three.js → нативный стек)

**Цифровой тамбур (framing, 10.08.2026):**
holograms.media — цифровой тамбур между «плоскими дисплеями» и «голографической реальностью». Голограмма — графический интерфейс с **несимвольным** (жестово-голосовым) взаимодействием в первую очередь. Не символы → GUI, а жест/голос → пространство → смысл. (Нейрокодер, 10.08.2026)

**GestureEmbedding (отложено, архитектурная цель):**
Жестовая модель (MediaPipe) ↔ Голографический бит ↔ Символьная модель (LLM). Минимальное соединяющее звено между жестовым и символьным мирами. Реализация будет в `js/engine/GestureEmbedding.js` (не мёртвый SmartHologram). Суть: траектории пальцев → эмбеддинги → parameter injection в LLM через function calling/embeddings. Маршрутизация жестами. (Нейрокодер, 10.08.2026)

**Проекция Gesture ↔ Symbolic (research milestone):**
Двойственная векторная проекция: символы (3072d LLM) + жесты (128d GestureDNA) →
единое пространство через projection matrix (обучение: Unsloth на AMD GPU).
Инференс: Qwen3.5 4B на XDNA2 NPU (gesture → LLM token → ответ → голограмма).
Голограмма = GUI для управления мультимодальным пайплайном: жест → звук → 3D → текст.
Стек: Unsloth (AMD GPU, fine-tune) + Qwen3 4B (NPU, инференс) + MediaPipe (жесты) +
Qwen3-TTS (голос). (Нейрокодер, 10.08.2026)
