## 1. Что такое проект (в двух предложениях для консультанта)

2026-10-14 02:13 MSK — Голографические медиа — это носитель, в котором звук закодирован в видимую трёхмерную структуру ДЛЯ МАШИННОГО ЗРЕНИЯ: читатель голограммы — камера, которая декодирует её обратно в звук; человек — не читатель, а автор (задаёт жестaми, как звучит место/предмет). Канон: `AGENTS.md` п.1-13 (критический инвариант), `docs/HOLOCONTRACT.md` (голоконтракт, Своя атмосфера, токеномика внимания), `Semitones_Angles.md` (азбука 128 полутонов и физика скейлограммы), `HologramsMedia.md` (манифест). Ключевое следствие для планирования: визуальная красота голограммы — НЕ цель, она несёт смысл только как адрес и форма визуального источника звука; задачи вида «улучшить внешний вид» отклоняются по построению.

2026-10-14 02:13 MSK — Технический стек после аудита 13.10.2026: фронтенд — единственный рендерер HoloEngine (WebGPU), Three.js/WebGL выведен из рантайма (создавал второй GPU-контекст = каскад invalid-texture в Firefox); жесткий трекинг рук — MediaPipe Hands (локально вендоренный); бэкенд — FastAPI на Koyeb (сигналинг, чат-бэкенд, JWT-авторизация через Google); деплой фронта — Cloudflare Pages по ветке `dev`, workflow на GitHub Actions; протокол сети — NetHoloGlyph (кванты жест/аудио между пирами по WebRTC DataChannel через сигнальный сервер).
