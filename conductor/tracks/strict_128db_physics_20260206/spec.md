# Спецификация: Строгая физика 128дБ и исправление Z-димминга

## Обзор
Переход на модель \"1дБ = 1 ячейка\" в диапазоне от -128 дБ до 0 дБ. Реализация физически корректного затухания яркости (димминга) в зависимости от энергии сигнала.

## Функциональные требования
1. **Честное сопоставление (Scale):**
   - Длина столбца (Z-scale) = `128 + current_db`.
2. **Физический димминг (Z-Dimming):**
   - Яркость (HSL Lightness + Emissive Intensity) пропорциональна длине.
   - `Emissive Intensity = current_cells / 128`.
   - `emissive` цвет материала = базовый цвет полутона.
3. **Rust Core Calibration:**
   - Базовый `pre_gain` = +30дБ для компенсации чувствительности микрофона.
   - Диапазон выхода: [-128, 0] дБ.

## Критерии приемки
- Тишина = Черные столбцы длиной 0.
- Яркость и длина синхронизированы.
- Усиление +30дБ в Rust.
