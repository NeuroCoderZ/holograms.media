# Спецификация: Стабилизация потока аудио и исправление визуальных багов

## Обзор
Устранение технических препятствий для передачи аудиоданных в рендерер и исправление визуального отображения кнопки переключения панелей.

## Функциональные требования
1. **Аудио:**
   - Принудительное «заземление» аудио-графа на `audioContext.destination`.
   - Гарантированный вызов `resume()` для `AudioContext` при взаимодействии пользователя.
   - Верификация возвращаемого значения `process()` в ворклете (должно быть `true`).
2. **Интерфейс (UI):**
   - Исправление селекторов иконок кнопки `#togglePanelsButton`.
   - Синхронизация визуального стиля кнопки (яркость/прозрачность) с общим UI.

## Критерии приемки
- В консоли появляются логи `[Flow Check]` с актуальными значениями dB.
- Иконка кнопки переключения панелей меняется корректно (Показать/Скрыть) без визуальных артефактов.
