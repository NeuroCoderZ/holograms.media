# Трек: Исправление Границ Рендеринга Голограммы

**Дата создания:** 2026-02-06  
**Приоритет:** 🟡 Высокий (визуальный баг)  
**Статус:** ✅ Завершено

## Контекст
После активации WASM-анализатора BasilaQ-127 обнаружено, что столбцы голограммы рендерятся за пределами отведенных сеток по оси X. Это нарушает визуальную симметрию и эстетику приложения.

## Проблема
Столбцы (Instances) выходят за границы X ∈ [-GRID_WIDTH, 0] для левой части и [0, +GRID_WIDTH] для правой. Вероятная причина — некорректная формула распределения шага (деление на общее количество вместо количества интервалов).

## Цели
1. Исправить расчет позиции `x` для `InstancedMesh`.
2. Обеспечить строгое соответствие столбцов границам `GRID_WIDTH` и `GRID_DEPTH`.
3. Сохранить симметрию между левым и правым каналами.
