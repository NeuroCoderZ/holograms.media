# Спецификация: Финальная синхронизация (EventBus и UI)

## Обзор
Исправление критических ошибок импорта EventBus, восстановление потока спектральных данных и окончательная фиксация визуального стиля кнопки переключения панелей.

## Функциональные требования
1. **EventBus Fix:** Исправить импорты `eventBus` (убрать фигурные скобки), так как используется экспорт по умолчанию.
2. **Heartbeat:** Добавить отладочные логи в `cwtAudioWorklet.js` для подтверждения работы цикла обработки.
3. **UI Lockdown:** Полностью исключить смену формы иконки кнопки `#togglePanelsButton`, оставив только модуляцию яркости.

## Критерии приемки
- В консоли появляются логи `Processing frame...` (раз в 100 кадров).
- Спектральные данные корректно доходят до рендерера через `eventBus`.
- Кнопка переключения панелей визуально стабильна (меняется только яркость).
