# Спецификация: Исправление целостности данных и димминга BasilaQ-127

## Обзор
Текущая визуализация BasilaQ-127 отображает некорректные данные в тишине (фантомные 60-70дБ) и имеет визуальные ошибки в логике димминга (смешивание каналов L/R). Задача: нормализовать математику в Rust, внедрить Noise Gate и исправить опечатки в рендерере.

## Функциональные требования
1. **Математическая точность (Rust):**
   - Нормализовать результат свертки (Dot Product) на длину вейвлета для возврата магнитуды в диапазон [0, 1].
   - Внедрить Noise Gate: при магнитуде < 0.0001 устанавливать значение -128.0 дБ.
   - Снизить `PRE_GAIN_DB` до 20.0 для предотвращения усиления шума.
2. **Исправление рендеринга (JS):**
   - Устранить опечатку в `updateVisuals`: блок обработки `rightMesh` не должен изменять свойства `leftMesh`.
   - Обеспечить независимость материалов столбцов для индивидуального димминга.
   - Синхронизировать `emissive` цвет с базовым цветом полутона.

## Критерии приемки
- В «мертвой тишине» столбцы имеют длину 0 и черный цвет (True Black).
- Левый и правый каналы визуализируются независимо.
- Отсутствие хаотичных прыжков столбцов при отсутствии входного сигнала.
