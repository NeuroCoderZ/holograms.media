# Спецификация: BasilaQ-127 Core — Биологически точный CWT-анализатор

## Обзор
Переработка ядра аудио-анализа `holocore` (Rust) для реализации истинного многомасштабного непрерывного вейвлет-преобразования (CWT). Текущая версия использует фиксированное окно, что не соответствует механике человеческого слуха. Новое ядро обеспечит индивидуальное разрешение для каждого из 128 полутонов, синхронизацию с FPS пользователя и физически корректный диапазон амплитуд.

## Функциональные требования
1. **Multi-Resolution CWT (Rust):**
   - Реализовать 128 независимых каналов анализа.
   - Для каждого канала использовать уникальный вейвлет Морле, длина которого обратно пропорциональна частоте полутона.
   - Внедрить кольцевой буфер (Ring Buffer) на 8192 сэмпла для хранения истории сигнала.
   - **Оптимизация:** Использовать усеченную свертку (truncated convolution). Длина вейвлета для каждого полутона ограничена участком затухания гауссиана до нуля.
2. **FPS-Driven Calculation:**
   - Анализатор должен накапливать данные непрерывно, но выполнять тяжелые вычисления спектра только один раз за кадр (согласно `target_fps`).
   - Синхронизация вычислений с частотой обновления экрана для предотвращения потери энергии сигнала и избыточных расчетов.
3. **Физика выходных данных:**
   - Диапазон амплитуд: 0 (True Black / Silence) до 128 (Max Intensity).
   - Разность фаз между L и R каналами для расчета панорамы (-1..1).
4. **Интеграция с Frontend:**
   - Автоматическое определение Refresh Rate устройства.
   - Передача FPS в AudioWorklet при инициализации.

## Критерии приемки
- Высокие частоты реагируют мгновенно (короткие вейвлеты).
- Низкие частоты отображаются плавно и глубоко (длинные вейвлеты).
- Отсутствие дрожания спектра на статичных сигналах.
- Загрузка CPU не превышает допустимых норм для 128 каналов на целевых устройствах (Tria Laptop).
