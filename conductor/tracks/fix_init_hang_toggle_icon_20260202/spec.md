# Спецификация: Исправление зависания и стиля иконки

## Обзор
Устранение критической ошибки блокировки основного потока при инициализации AudioContext и исправление визуального поведения кнопки переключения панелей.

## Функциональные требования
1. **Аудио:**
   - Сделать возобновление AudioContext неблокирующим (убрать `await`).
   - Позволить `initializeCwtWorklet` завершаться успешно даже если контекст в состоянии `suspended`.
2. **Интерфейс (UI):**
   - Закрепить одну статичную иконку для `#togglePanelsButton`.
   - Реализовать индикацию состояния через яркость/прозрачность вместо смены формы иконки.

## Критерии приемки
- Приложение загружается без бесконечного экрана загрузки.
- Кнопка переключения панелей сохраняет форму иконки при нажатии, меняя только яркость.
