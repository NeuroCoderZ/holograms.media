# Спецификация: Глубокая синхронизация (Аудио и UI)

## Обзор
Исправление критических ошибок импорта EventBus, восстановление потока данных из WASM и окончательная блокировка визуальных изменений иконок управления.

## Функциональные требования
1. **Audio Flow Repair:** Исправить импорты `eventBus` во всех аудио-модулях (удалить фигурные скобки).
2. **UI Lockdown:** Исключить смену формы иконки кнопки полноэкранного режима, оставив только изменение яркости.
3. **UX Improvement:** Обновить подсказки (tooltips) для кнопки переключения панелей.
4. **Automation:** Внедрить правило автоматического закрытия треков в Workflow.

## Критерии приемки
- Спектральные данные корректно поступают в `eventBus`.
- Иконка полноэкранного режима не меняет форму при нажатии.
- Подсказки кнопки переключения панелей соответствуют текущему состоянию.
