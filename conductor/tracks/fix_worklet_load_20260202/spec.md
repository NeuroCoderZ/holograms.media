# Спецификация: Исправление загрузки AudioWorklet (Vite URL import)

## Обзор
Устранение ошибки `AbortError` при инициализации `AudioWorklet`. В среде Vite прямые пути к JS-модулям ворклетов могут не разрешаться корректно, особенно после сборки (production).

## Функциональные требования
- Заменить жестко заданный путь `/js/audio/cwtAudioWorklet.js` на динамический импорт Vite с использованием суффикса `?url`.
- Гарантировать, что `AudioService` получает корректный URL для метода `addModule`.

## Приемочные критерии
- Метод `initialize()` в `AudioService.js` успешно загружает модуль ворклета без `AbortError`.
- В консоли браузера подтверждается успешная загрузка: `[AudioService] AudioWorklet module loaded`.

## Вне рамок (Out of Scope)
- Изменение логики работы самого ворклета.
- Оптимизация WASM-части.
