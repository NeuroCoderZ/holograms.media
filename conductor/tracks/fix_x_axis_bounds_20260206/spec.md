# Спецификация: Физически корректные границы и димминг голограммы

## Обзор
Исправление выхода столбцов за границы оси X и внедрение физически корректной модели освещенности. Столбцы должны быть жестко ограничены сеткой (GRID_WIDTH=128), а их яркость должна зависеть от их длины (глубины Z).

## Функциональные требования
1. **Жесткие границы X (Restraint):**
   - Left Grid: X ∈ [-128, 0].
   - Right Grid: X ∈ [0, 128].
   - Использовать `userData.initialX` как базу для исключения дрейфа.
2. **Физика Света (Z-Depth Dimming):**
   - Яркость (Emissive Intensity) прямо пропорциональна длине столбца.
   - Формула: `Intensity = Current_Z_Cells / 128`.
   - 0 ячеек = True Black, 128 ячеек = 100% яркость.
3. **Источник Истины:**
   - Верификация углов (`deg`) и цветов (`hsl`) по файлу `Semitones_Angles.md`.

## Критерии приемки
- Столбцы не пересекают границы X=0 и X=±128.
- При затухании звука (уменьшении Z) столбцы плавно уходят в черный цвет.
- Вертикальная архитектура сохранена.
