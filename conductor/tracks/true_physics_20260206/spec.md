# Спецификация: Истинная физика рендеринга (Z-Dimming и Pan-Constraint)

## Обзор
Текущая визуализация BasilaQ-127 нарушает физическую модель «Кохлеарного Цилиндра». Столбцы разной амплитуды светятся одинаково, а панорамирование не учитывает ширину столбцов. Задача: внедрить строгую зависимость яркости от длины (Z) и ограничить панорамирование (X) в зависимости от ширины частотного диапазона (Width).

## Функциональные требования
1. **Z-Depth Dimming (Физика Света):**
   - Яркость столбца (HSL Lightness и Emissive Intensity) должна быть линейно привязана к его длине по оси Z.
   - Амплитуда 0 (тишина) = True Black (0% яркости).
   - Амплитуда Max (128 ячеек) = 100% яркости (базовый цвет из конфига).
   - Обеспечить дискретность в 128 градаций.
2. **Width-Dependent Pan (Геометрия Панорамы):**
   - Максимальное смещение по оси X (`availableSpace`) рассчитывается как `GRID_WIDTH (128) - columnWidth`.
   - Результирующее смещение: `xOffset = panValue * availableSpace`.
   - Санитизация `panValue` в диапазоне [-1, 1].
   - Низкие частоты (широкие столбцы) имеют меньший диапазон движения, высокие (узкие) — больший.
3. **Сохранение архитектуры:**
   - Сохранить вертикальную ориентацию (Y = индекс частоты).
   - Сохранить использование `userData.initialX` для предотвращения дрейфа.

## Критерии приемки
- Столбцы тускнеют при уменьшении длины (Z).
- Широкие столбцы (бас) остаются ближе к центру, узкие (высокие) свободно перемещаются по всей сетке.
- Визуальное соответствие физической модели энергии.
