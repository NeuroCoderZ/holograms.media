# Технический Бриф для Claude: Проблемы с Динамикой и Физикой Визуализации

## Контекст
Мы разрабатываем 3D аудиовизуализацию на Three.js, где 128 вертикальных столбцов представляют 128 частотных полос (полутонов). Цель — "Активная Физика":
- **Высота (Z)**: Строго привязана к уровням дБ. 0 дБ = Макс Высота, -128 дБ = 0 Высота.
- **Яркость**: Должна нелинейно затухать с высотой. -128 дБ должно быть "черной тишиной".
- **Главная проблема**: Визуализация ощущается "плоской", не хватает глубины динамического диапазона, а на тихих треках (например, Piano) все столбцы "дрожат" на уровне 50-60% высоты вместо того, чтобы быть минимальными.

## Текущая Реализация
1. **Аудио Пайплайн**:
   - `cwtAudioWorklet.js` выполняет CWT (Continuous Wavelet Transform).
   - `lib.rs` (WASM) вычисляет магнитуду и переводит в дБ: `20.0 * log10(magnitude)`. Обрезается диапазоном `[-128.0, 0.0]`.
   - `hologramRenderer.js` мапит дБ в визуальные свойства.

2. **Визуальный Маппинг (Текущий код, требует проверки)**:
   ```javascript
   // hologramRenderer.js
   const getNormAmp = (db) => {
       const safeDb = Math.max(-128, Math.min(0, db));
       let physicalHeight = safeDb + 128; // Диапазон 0..128
       
       // Headroom Scale 0.9 (0 дБ = ~115 единиц)
       const displayHeight = physicalHeight * 0.9; 

       // Яркость (Квадратичная)
       const ratio = physicalHeight / 128.0;
       const brightness = Math.pow(ratio, 2.5); // Глубокая кривая

       return { length: displayHeight, brightness: brightness };
   }
   
   // Применение
   mesh.scale.z = Math.max(0.01, norm.length);
   mesh.material.emissiveIntensity = norm.brightness;
   mesh.material.color.setHSL(h, s, l * norm.brightness);
   ```

## Проблемы (Которые нужно решить)
1. **"Дрожащий Пол"**: Даже на тихом фортепианном треке все столбцы вибрируют на высоте 50-60 (-70 дБ?). Это говорит о том, что наш Noise Floor или нормализация CWT работают некорректно. Нам нужно отсечь этот шум или мапить его в 0.
2. **"Плоская" Картинка**: Несмотря на `brightness^2.5`, визуализация выглядит "плоской", а "низы" не кажутся по-настоящему темными.
   - *Подозрение*: Возможна проблема с материалами Three.js или отсутствием правильной гаммы.
   - *Подозрение*: "Шумовая полка" записи визуализируется как полезный сигнал среднего уровня.
