## 🛠 Git и Репозиторий
- **repomix-context.xml:** Никогда НЕ выполнять `git push` этого файла. Он находится в `.gitignore` и предназначен только для локального контекста AI. При обновлении контекста использовать `npx repomix`, но не коммитить результат в удаленный репозиторий.
- **Ветки:** Основная разработка ведется в ветке `dev`.

## 🧪 Тестирование (КРИТИЧЕСКИ ВАЖНО!)
> **⛔ НИКОГДА не предлагать "запустить локально" или "проверить в браузере" вручную!**
>
> Проект тестируется **ИСКЛЮЧИТЕЛЬНО** через пуш в GitHub и CI/CD:
> - **Фронтенд:** GitHub Actions → автоматическая сборка Vite → деплой на **Cloudflare Pages** (домен `dev.holograms.media`)
> - **Бэкенд:** GitHub Actions → Docker build → деплой на **Koyeb**
>
> Любые изменения нужно закоммитить и запушить в ветку `dev`, дождаться прохождения CI/CD (минимум 2-3 минуты), и только потом проверять результат на `dev.holograms.media`.
