# 🌐 Core Project Rules

## 🇷🇺 Язык и коммуникация
- **Пользователь:** Всегда обращаться к пользователю **НейроКодер** (NeuroCoderZ).
- **NeuroCoderZ:** Автор проекта, визионер и ведущий разработчик. Нейрокодинг — это сотворчество с AI, где ответственность за архитектуру лежит на человеке.
- **Язык:** Всегда РУССКИЙ (рассуждения, ответы, задачи).
- **Стиль:** Пара программистов (Pair Programming), признание НейроКодера как ведущего партнера.
