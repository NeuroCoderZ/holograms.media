## 🔴 Проблема 1: Koyeb 500 — `httpx.InvalidURL: Invalid port: 'ASTRA_DB_API_ENDPOINT'`
**Симптомы:**
Бэкенд впадает в 500 ошибку при вызове `/chat_sessions/direct`. В логах: `ValueError: invalid literal for int() with base 10: 'ASTRA_DB_API_ENDPOINT'`.
**Анализ:**
В предыдущем скрипте деплоя Koyeb CLI создавал секрет со значением `""` (пустая строка), потому что ссылался на `${{ secrets.ASTRA_DB_API_ENDPOINT }}`, которого нет в GitHub (там он называется `ASTRA_DATABASE_URL`). Из-за пустого значения Koyeb, видимо, просто запихнул туда строку `"ASTRA_DB_API_ENDPOINT"`, из-за чего питоновский `httpx` начал парсить её как порт.
**Твоя задача:**
Я уже обновил `koyeb-dev-deploy.yml` (строка 26) на правильный `secrets.ASTRA_DATABASE_URL`. Тебе нужно сделать **пуш/деплой**, проверить логи Koyeb и убедиться, что DNS-проблема исчезла и чат Триа поднялся.

## 🔴 Проблема 2: Плоские столбцы BasilaQ при воспроизведении (Audio = OK, Render = Flat)
**Симптомы:**
Аудио проигрывается, логи `audioProcessing.js` показывают корректные значения (например, `max=-48.50`). Но столбцы не поднимаются.
**Анализ:**
1. Текущий код в `hologramRenderer.js` пытается изменять высоту через `dummy.scale.set(width, 1, hL);` + `this.meshL.setMatrixAt(i, dummy.matrix);`. 
2. По запросу пользователя я выгрузил старую 100% рабочую версию рендерера недельной давности в файл `c:\holograms.media\.agent\hologramRenderer_old.js`.
3. В старой (рабочей) версии масштаб передавался **не через матрицу**, а через кастомный буфер `1D`: `lScales.setX(i, hL);` (атрибут `aColumnScaleZ`), и это обрабатывалось внутри GLSL `hologramShaders.js`!
**Твоя задача:**
Скорее всего, текущий `hologramShaders.js` всё ещё ожидает параметр `aColumnScaleZ`, который из нового `hologramRenderer.js` был случайно удалён при рефакторинге на чистый `setMatrixAt()`.
Сравни старый файл `.agent/hologramRenderer_old.js` с новым `js/3d/hologramRenderer.js` и шейдерами `js/3d/shaders/hologramShaders.js`. Либо верни поддержку `aColumnScaleZ`, либо перепиши вершинный шейдер так, чтобы он корректно использовал `instanceMatrix` для скейла высоты.

## 🟡 Проблема 3: Блики стали белыми (вместо разноцветных)
**Симптомы:**
UI-компоненты (кнопки, вкладки) отбрасывают "белое свечение" (GlassSpecularManager) вместо цветного градиента от визуализатора.
**Анализ:**
Это следствие Проблемы 2. Блики напрямую берут цвета с холста (рендера). Поскольку столбцы лежат "плоскими" и не светятся (или их не видно на фоне), менеджер бликов захватывает пустой/дефолтный пиксель сцены и генерирует белое/нейтральное свечение.
**Твоя задача:** 
Как только ты победишь Проблему 2 (столбцы поднимутся и нальются цветом), блики чудесным образом починятся сами. Если нет — проверь в `GlassSpecularManager` настройки MutationObserver или координату выборки контекста канваса.
