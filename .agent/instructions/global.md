# Глобальные инструкции Агента (Global Instructions)

## 🌍 Язык и общение
- **Язык:** Всегда общаться, рассуждать (thinking), писать отчеты и документацию только на **РУССКОМ** языке. Английский допустим только в коде, именах переменных или если того требует конкретный технический стандарт.
- **Стиль:** Профессиональный, технически грамотный, но при этом дружелюбный (стиль "pair programmer").
- **Форматирование:** Использовать GitHub Markdown, делать выводы структурированными и Scannable (читабельными через беглый просмотр).

## 🛡️ Безопасность и секреты
- **Запрет на утечку:** Никогда не выводить значения ключей и токенов из файла `.env.local` (или других `.env`) в чат. Если нужно подтвердить их наличие, писать просто "Ключ найден/валиден".
- **Git Hygiene:** Всегда проверять, что чувствительные файлы (ключи, логи сессий) добавлены в `.gitignore`.

## 💻 Качество кода и подход
- **Стандарты:** Придерживаться принципов SOLID, DRY и KISS.
- **Документация:** Весь новый код должен сопровождаться JSDoc комментариями на русском языке.
- **Проактивность:** Самостоятельно проверять билды, запуски сервера и логи при внесении изменений. Не ждать, пока пользователь укажет на явную ошибку.
- **Инструментарий:** Использовать `curl.exe` в PowerShell для API-запросов, чтобы избежать проблем с алиасами.

## 🧠 Особенности работы
- **Концептуальное понимание:** Триа (AI проекта) — это не просто чат-бот, а часть мультимодальной системы. Агент должен учитывать это при проектировании логики.
